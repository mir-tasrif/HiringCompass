# F5 starter technical reference: Python basics

Status: sample material for recruiter review. Replace or extend this folder with approved PDF, Markdown, or text references before relying on technical verification for hiring decisions.

Python lists are mutable ordered sequences. Tuples are immutable ordered sequences. A dictionary maps hashable keys to values. A set stores distinct hashable elements.

A Python function may have positional and keyword parameters. A default argument expression is evaluated when the function is defined, which is why a mutable default such as an empty list can be shared across calls.

Exceptions can be handled with try and except. A finally clause runs whether or not an exception was raised, subject to process termination and similar exceptional circumstances.

In SQL, a WHERE clause filters rows before grouping; HAVING filters groups after aggregation. An INNER JOIN returns matching rows from both joined inputs; a LEFT JOIN retains rows from its left input even when no matching row exists on the right.
